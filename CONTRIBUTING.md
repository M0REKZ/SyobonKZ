Contributing
-----

Follow these rules or your contribution may be declined:

* Before anything, make an issue about the feature
 or bug you want to fix, it may have been fixed already,
 the feature may not be necessary or it could be made
 in a better way.
* I know this is C++ but please avoid using classes,
 lets keep the code simple.
* Dont vibecode.

Also i dont strongly enforce this coding format, but:
* Prefix pointers with a p (```pExample```)
* Local variables must be lower case,
 each word separated with a underscore (```local_var```)
* Global variables must start with a capital letter (```GlobalVar```)
* Avoid using references, use pointers instead
