SyobonKZ incorporates code and other materials from several projects with different origins and licensing histories:

- Open Syobon Action — "DxLib.cpp", "DxLib.h" and "joyconfig.h": These files contain the SDL implementation derived from Open Syobon Action and are distributed under GNU General Public License version 2 (GPLv2).
- Bluvel's Shobon Action 2 — "main.cpp", "main.h", "loadg.cpp", and "loadg.h": These files seems to originate from Bluvel's modified version of the original Shobon Action and were subsequently modified by Open Syobon Action.
- Original Shobon Action by Chiku: The original source was released with permission to modify, accompanied by a request not to redistribute the source in its original form.

- SyobonKZ modifications: This project includes porting, refactoring, compatibility improvements, new features, and other modifications.

The code and other materials in this repository therefore have multiple origins and licensing histories. The included GPLv2 license applies to the portions identified as GPLv2-licensed; it should not be interpreted as automatically relicensing all code or other materials of different origins.

Original authors and contributors are acknowledged where known. Additional provenance or licensing information may be documented as it becomes available.
